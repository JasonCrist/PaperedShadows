Assembly Instructions

  1. Cut each layer on cardstock or mat board using your Cricut
  2. Stack layers from back (Layer 1) to front (Layer 5)
  3. Use foam spacers or mounting tape between layers (0.25" recommended)
  4. Add LED strip or backlight behind Layer 1 for stunning illumination
  5. Frame in a shadow box frame with appropriate depth
